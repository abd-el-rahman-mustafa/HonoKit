# Security policy

HonoKit opens files that come from anywhere, so problems such as a document that can run code,
read or write files it should not, open a link without asking, or get past a password or a
redaction are taken seriously.

## Reporting a vulnerability

**Please do not open a public issue.** Report it privately through GitHub:

1. Go to the repository's **Security** tab.
2. Choose **Report a vulnerability**
   ([direct link](https://github.com/abd-el-rahman-mustafa/HonoKit/security/advisories/new)).

Please include the HonoKit version (Settings › About), your operating system, the steps to
reproduce it and, if possible, a file that shows it. Only send a file you are allowed to share.

You should get a first answer within a week. Once a fix is released, the advisory is published
and you are credited, unless you would rather not be.

## Supported versions

Only the latest release
([HonoKit-Releases](https://github.com/abd-el-rahman-mustafa/HonoKit-Releases/releases/latest))
gets security fixes. The installed app updates itself unless the update check is turned off.
